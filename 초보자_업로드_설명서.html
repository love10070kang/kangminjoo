EDS 라인기획 플랫폼 · 전체 교체 안내

2026-11-17 · v4.0 │ 프로그래밍 없이 파일 복사 + GitHub Desktop 업로드

필독: 기존 Repository를 바로 삭제하지 마세요.

먼저 백업하세요. 기존 설비 데이터, 변경이력, Pages 설정이 지워질 수 있습니다. 새 ZIP에는 데이터 JSON이 들어 있지 않아 원래 저장소의 data 폴더를 유지해야 정상 동작합니다. 그리고 현재 인터넷에서 보이는 love10070kang/kangminjoo 저장소는 Public입니다. 사내 기밀은 업로드하지 마세요.

1. 기존 사이트 전체 백업

  1. 저장소 열기
  2. Code → Download ZIP 클릭
  3. 받은 ZIP 이름을 BACKUP_이전버전.zip으로 두고 삭제하지 않기

2. 새 ZIP 압축 해제

  1. EDS_LinePlanning_2026-11-17_v4.0.zip 우클릭
  2. 압축 풀기 클릭
  3. 생성된 프로젝트 폴더를 열어 index.html · app.js · line-info.html 파일 등이 있는지 확인

중요: 프로젝트 폴더 자체가 아니라 안의 내용을 저장소에 복사합니다.

3. GitHub Desktop 사용 (권장 · 처음만 설정)

  1. GitHub Desktop 실행 및 GitHub 계정 로그인
  2. File → Clone repository 클릭
  3. 목록에서 love10070kang/kangminjoo 선택
  4. 컴퓨터에 저장할 위치 선택 후 Clone 클릭
  5. Repository → Show in Explorer 클릭

사내 GitHub를 쓰는 경우 해당 기업용 Desktop 로그인/클론 권한이 있어야 합니다.

4. 전체 파일 복사 (기존 수동 코드 수정 불필요)

  1. 2단계에서 압축 푼 프로젝트 폴더 열기
  2. 폴더 안의 파일과 data 폴더를 선택하여 Ctrl+C
  3. 3단계의 GitHub Desktop 저장소 폴더를 열고 Ctrl+V
  4. 기존 파일과 이름이 같다는 창에서는 파일 바꾸기(Replace) 선택
  5. 기존 폴더에 있는 .git, .github, CNAME은 삭제하지 않기

완전한 사이트 코드 교체는 이 방법으로 가능합니다. 기존 data 폴더는 이번 ZIP에 들어 있지 않으므로 그대로 보존됩니다. data 폴더는 삭제하지 마세요.

5. GitHub에 일괄 적용

  1. GitHub Desktop으로 돌아오면 Changes에 변경된 파일들이 표시됨
  2. 변경목록에서 예상치 못한 삭제(Deleted)나 데이터 변경이 없는지 확인
  3. Summary에 EDS LinePlanning 2026-11-17 v4.0 입력
  4. Commit to main 클릭
  5. Push origin 클릭

6. 홈페이지 확인

  1. GitHub Actions에서 배포 성공 확인
  2. 메인 대시보드 접속
  3. 01 라인 기본정보 클릭
  4. 라인 기본정보에서 왼쪽 05 설비투자 선택 → 다른 메뉴로 이동하는지 확인
  5. 다시 01 라인 기본정보로 돌아와 그래프 최대화, Raw 다운로드, 변경이력 확인

다음 버전에도 같은 방식으로

새 ZIP 받기 → 압축 풀기 → 프로젝트 폴더 안의 내용 복사 → GitHub Desktop에서 Commit → Push.
