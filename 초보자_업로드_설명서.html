프로그램 설치 불필요 · 파일 덮어쓰기 + README/OpenCode 문서 같이 업로드

업로드 전 꼭 읽어주세요

기존 저장소의 파일을 전부 삭제하면 안 됩니다. 특히 data/equipment.json과 data/line-info-state.json은 기존 업무 자료·이력입니다. 이번 ZIP에는 포함되지 않으며 그대로 보존해야 합니다. 실제 회사 기밀은 공개 저장소에 올리지 마세요.

1 기존 GitHub 저장소 백업

  1. GitHub 저장소 열기
  2. Code → Download ZIP 선택
  3. 받은 ZIP 파일을 안전한 곳에 별도로 보관

2 새 v4.3 ZIP 압축 풀기

  1. EDS_LinePlanning_2026-11-17_v4.3.zip 다운로드
  2. 파일 우클릭 → 모두 압축 풀기
  3. 압축 해제 폴더를 열고 아래 파일 확인
index.htmlline-info.htmlapp.jsstyle.cssnav.js ★nav.css ★README.md ★AGENTS.md ★md/ 폴더 ★

★ 이번 버전에서 메뉴 디자인 통일 및 OpenCode 인수인계를 위해 중요한 파일입니다.

3 GitHub 홈페이지 업로드

  1. 저장소 Code 화면에서 Add file → Upload files 클릭
  2. ZIP 압축 해제 폴더 안의 최상위 파일을 선택하여 업로드 영역에 드래그
  3. md/ 폴더가 경로 그대로 들어가도록 업로드. 브라우저에서 폴더 드래그가 지원되지 않으면 개별 파일을 md/파일명.md 경로로 생성
  4. 파일 목록 확인 후 Commit changes 클릭

ZIP 파일 자체만 업로드하면 홈페이지가 갱신되지 않습니다. 압축 해제된 HTML·CSS·JS 파일이 필요합니다.

주의: 덮어쓰기 전에 반드시 확인

  • 기존 data 폴더와 JSON 데이터는 삭제하지 않기.
  • 실사용 중인 equipment.html은 시연용 ZIP 파일로 함부로 덮어쓰지 않기.
  • .github/, CNAME, 기존 운영 파일은 그대로 유지.
  • 이번 릴리스에는 nav.js / nav.css / AGENTS.md / md/ 문서가 추가됨. 폴더 경로가 깨지지 않았는지 확인.

4 업데이트 후 정상 동작 확인

  1. GitHub에서 배포가 끝나면 홈 대시보드 접속
  2. 01. 라인 기본정보 접속
  3. Ctrl + F5로 강력 새로고침
  4. 두 화면 메뉴 디자인 일치(6그룹/16메뉴), 그룹 펼침, 좌측 메뉴 접기 확인
  5. 01의 Raw 표를 세로+가로 스크롤해도 제목 위로 데이터가 겹치지 않는지 확인
  6. Raw 표·그래프 최대화 ↔ 원래대로 확인
  7. GitHub의 md/00_START_HERE.md과 AGENTS.md가 열리는지 확인
