## 자주 발생했던 실수

1. 화면 이미지에 왼쪽 16개 메뉴가 누락됨 → 반드시 모두 표시/스크롤로 접근 가능.
2. 홈과 01의 메뉴 이름·배치·아이콘이 서로 달라짐 → `nav.js`와 `nav.css` 공통 소스 하나만 유지.
3. 한 모니터에서 KPI가 두 줄이 되고 차트가 좁아짐 → 콘텐츠 공간 우선, 관리 패널 기본 접힘.
4. Raw/차트 최대화 시 패널만 커지고 데이터 내용은 그대로임 → 최대화 시 차트/테이블 레이아웃 확대.
5. Raw 세로/가로 스크롤에서 행이 상단 그룹·필드명 위로 겹침 → 헤더 레이어 우선순위/고정 열 교차 처리.
6. Excel RAW 열에 사용자 승인 없이 메타데이터/차압/As-built 등 추가 → 현재 46열을 진실의 출처로 간주.
7. 브라우저 시연 비밀번호를 실무 보안 기능이라고 설명 → 허위 보안 주장 금지.
8. 기존 실제 data/ 원본을 가상 데이터로 교체 → 자료 손실 위험. 배포 ZIP에서 기존 data/ 제외.

## 후속 변경 요청 처리

최소한 `어떤 파일을 바꿀지 / 어떤 승인 기능을 그대로 유지할지 / 어떻게 실제 브라우저 검증할지`를 기록하고, 테스트 결과가 없는 기능은 완성이라고 주장하지 않는다.
