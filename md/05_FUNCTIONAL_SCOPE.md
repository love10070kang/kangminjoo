# 05. 기능 현황표 — 이미 동작하는 것 / 부분 구현 / 아직 미구현

**모든 문구는 현재 v4.3 정적 소스를 기준으로 작성**합니다. 회사 GitHub 실계정/원격 저장소에서 보안·권한 검증을 완료했다고 주장하지 않습니다.

| 기능 | 현재 상태 | 근거/주의 |
|---|---|---|
| 6개 그룹·16개 메뉴 | 구현 | `nav.js`에서 공통 렌더링. 01 외 상세 화면 대부분 플레이스홀더 |
| 홈 통합 대시보드 | 시연 구현 | `index.html`/`app.js`. KPI/알림/3D 콘셉트는 가상 값 |
| 01 KPI 5개/그래프 3개/RAW 표 | 시연 구현 | `line-info.html` 샘플 또는 접근 가능한 JSON 참조 |
| 상단 조건 필터/라인 클릭 연동 | 구현 | 화면 조회 대상 변경 |
| 차트·RAW 최대화/원래대로 | 구현 | 최소화 버튼 없음. ESC 복귀 |
| 46열 Excel 최신/양식 다운로드 | 구현 | 브라우저에서 생성·파일 다운로드. 업무 원본 여부 확인 필요 |
| Excel 업로드 데이터 읽기/검증/비교 | 시연 구현 | 클라이언트 내부 XLSX 처리. 파일 최대 5MB 등 제한 |
| 버전별 스냅샷·변경이력 | 로컬/조건부 | localStorage에서 저장; GitHub에 공유 반영하려면 인증된 원격 쓰기 필요 |
| `data/line-info-state.json` 공유 읽기 | 조건부 구현 | 파일이 해당 경로에 공개 접근 가능한 경우 읽기 시도. 사내 비공개 환경 제한 |
| GitHub API 쓰기 | 조건부 시연 | 토큰 입력 UI 존재하지만 정식 사내 인증·SSO·권한 설계 미완성. 운영용 권장 X |
| 업로드 시연 비밀번호 | 테스트용만 | `edseds`는 브라우저에 노출되는 문자열로 보안 기능이 아님 |
| GitHub Actions 승인/CI 검증 | 미구현/환경 의존 | 회사 저장소 Ruleset/Actions와 별도 개발 필요 |
| 일반 직원/수정자/승인자 권한 | 미구현 | 회사 GitHub Enterprise 관리자와 최종 단계 설계 |
| 사내 데이터 연결/DB/SSO | 미구현 | 보안 승인 및 서버/인증 설계 필요 |
| 02~16 실제 업무 CRUD | 미구현 | 메뉴 연결과 안내 화면만 유지. `equipment.html` 이전 파일 별도 |
| 실제 AI 검색/추론/배치 시뮬레이션 | 미구현 | 버튼/시안이 있다면 실제 결과를 생성하는 것이 아님 |
| 교육·역량 L1~L7 운영 | 요구사항 수준 | 현재 배포 UI에는 미반영, 추후 기획 |

## 현행 운영 워크플로 (데모)

`홈 또는 01 접속 → 필터/그래프 조회 → 최신 RAW 다운로드 → Excel 수정 → 파일 검증 → 변경 검토 → 최종 반영(로컬 또는 조건부 원격) → 변경이력 확인`

**중요:** 브라우저 localStorage 버전은 다른 직원이나 PC에 자동 동기화되지 않음. 원격 쓰기 연결은 별도의 권한/보안 검토가 필요합니다.
