# 01. 프로젝트의 배경·취지·업무 이해 (왜, 누구를 위해, 무엇을 위해)

## 문제 인식

반도체 EDS 라인기획 업무는 라인, FAB, 층, 설비, 공사, 자원(Utility), 도면과 변경이력이 서로 연결되어야 합니다. 그러나 자료가 담당자별 엑셀/도면 폴더로 흩어지고 데이터 정의가 통일되지 않으면 새 업무가 들어올 때마다 정보를 재수집해야 하며, 담당자에 따라 검토 결과와 근거가 달라집니다. 신규 인력에게 실무 전체 과정을 교육하는 데도 어려움이 생깁니다.

**플랫폼의 목적은 보기 좋은 홈페이지 자체가 아니라 '같은 기준으로 올바르게 판단하고, 검토 과정과 근거를 반복 활용하도록 하는 것'입니다.**

## 확정된 4대 최상위 목적

1. **전문가 육성**: 신입(L1 등)부터 마스터(L7)까지 단계적 성장 지원.
2. **업무 표준화**: 용어/입력자료/검증/결정/결과를 동일 프로세스로 관리.
3. **교육과 실무 연결**: 학습→현장 수행→산출물→검토→역량 증빙까지 연결.
4. **조직 혁신·미래 기술**: AI 검색, 자동화, 시뮬레이션, 비교·벤치마킹 지원.

## 사용자 6종

- 신입: 라인·FAB·설비·도면·반입·Utility 기초를 이해하고 교육받음.
- 실무: 수용성/배치/도면/협의/일정 실무 처리 및 데이터 조회·갱신.
- 선임·전문: 기준 검토, 정합성 확인, 멘토링, 예외 대응.
- 마스터·전문가: 고난도 평가, 기준 고도화, 전략적 설계 검토.
- 관리자(파트장/그룹장): 업무·리스크·일정·승인·인력 역량 현황.
- 유관부서: 사업장, 시설, 생산, 안전, 공사와 협업하는 범위 내 조회/검토.

## 8개 핵심 업무 범위

1. 생산계획·수요 협의(공동)
2. FAB 공간·설치 조건(라인기획 주관)
3. 설비 Layout 설계(주관)
4. 설비 제원·Utility 수용성(공동)
5. 반입 동선·접근성(공동)
6. 현장 적합성 확인(주관)
7. 유관부서 협의·승인(공동)
8. 최종 도면 및 변경이력 관리(주관)

## 업무 착수 유형 9개

신규 라인 / 라인 증설 / 신규 설비 / 이전·재배치 / 반출·철거 / 제원·시설 변경 / 효율화·공간 최적화 / 중장기 전략 / 긴급 이슈.

## 공통 실무 프로세스

`요청 → 입력자료 확보 → 설치 수용성 판단 → Layout 설계 → 협의·승인 → 현장 적합성 확인 → 최종 도면·변경이력 정리`

기본 최종 산출물은 **승인된 최종 Layout 도면**과 **도면 개정·변경이력**. 단순히 마지막 저장날짜가 최신이라는 이유로 '승인본'이라고 판단하지 말 것. 원본·구버전은 기존 사내 파일 서버를 존중하고 플랫폼에서는 링크/메타데이터로 연계한다.

## 성공 기준 8가지

설비 수용성 / 공간 최적화 / 시설·설치 적합성 / 일정 준수 / 비용 최적화 / 안전·정비성 / 운영·품질 안정 / 문서화·변경관리.

## 차후 교육/역량 플랫폼 확장(현재 v4.3 화면에 구현되지 않음)

- L1~L7 단계별 역량 및 교육·실습·평가·인증 체계.
- L3에서는 교육·실무 경험·최종 산출물을 종합하여 PASS/N/A 체크리스트 기반 선임 검토.
- 멘토링(전담 멘토+전문가), L4~L7 전문성 증명, 관리자 승인.
- 개인별 현재/목표 레벨, 학습·실습, 진행 업무, 승인 대기, 역량 현황 등 대시보드.
- 교육/역량/업무/도면 표의 세부 구조는 추후 별도 인터뷰·승인에 따른다. **현재 16개 라인정보 업무 메뉴를 임의로 9개 교육 메뉴로 교체하지 말 것.**

## 01 라인 기본정보가 중요한 이유

장비 신규 도입·증설 시 공간이 '보인다'는 것만으로 설치 가능하다고 결론 낼 수 없습니다. 동일 층의 가용면적, 하중, 층고, Access Floor 하부, 반입구 규격, 승강기, 환경 및 최종 도면을 함께 확인해야 합니다. 01은 이후 06 설비 Layout과 07 설비 제원정보의 입력 토대가 됩니다. **설치 가능 판정 자동화는 조건 정의·검증 후 단계적으로 도입**합니다.
