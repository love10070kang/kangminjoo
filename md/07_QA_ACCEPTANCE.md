# 07. 개발자/사용자 최종 승인 테스트 체크리스트

**모든 항목을 통과하지 못하면 완성이라고 표현하지 말고 미검증/실패 항목을 기록한다.** 최소한 Chrome/Edge 기준 1437×770, 1600×900, 1920×1080 테스트.

## 공통 메뉴 (홈 + 01)

- [ ] 두 화면 사이드바가 색/폰트/아이콘/그룹/링크 위치까지 **같은 CSS·JS 소스(`nav.js`, `nav.css`)**를 사용.
- [ ] 그룹 수 정확히 6개; 세부 항목 16개(4/4/2/2/3/1).
- [ ] HOME은 홈 강조, 01 페이지는 `01 라인 기본정보` 강조.
- [ ] 6개 그룹 개별 접기/펼치기, 왼쪽 메뉴 스크롤, 메뉴 전체 접기/펼치기 작동.
- [ ] 01에서 홈으로/홈에서 01로 이동, 02~16은 404가 아닌 안내 화면 열기.
- [ ] 좌측 메뉴는 메인 대시보드 KPI/차트를 덮거나 잘라내지 않음.

## 01 화면 일반 배치

- [ ] 다섯 KPI가 일반 데스크톱 한 줄에 보임; 정확한 숫자·단위 존재.
- [ ] 세 그래프 제목·범례·축·숫자·단위가 읽기 쉬움; 작은 화면 겹침/잘림 없음.
- [ ] RAW 첫 행 일부가 한 화면에 보이고 내부 표 세로 스크롤 가능.
- [ ] 기존 엑셀/검증/이력/필터/라인 비교/품질 버튼 동작 유지.
- [ ] 최소화 버튼이 **없음**.

## RAW 헤더/행 겹침 문제 회귀 테스트(중요)

1. RAW를 스크롤하지 않고 `라인 ID/라인명/층`과 위쪽 그룹 헤더 2줄 정상 표시 확인.
2. Raw 내부 세로 스크롤을 중간까지 진행: **본문의 L02/B라인/3F 등이 헤더 윗줄로 들어오면 실패**.
3. 가로 스크롤 400px 진행: 라인 ID/라인명/층 고정, 왼쪽 헤더 교차부가 본문과 겹치지 않을 것.
4. 가로 400px+세로 150px **동시에** 스크롤; 그룹 헤더와 필드명 모두 본문 위에 렌더링될 것.
5. RAW `최대화`: 뷰포트 내부 너비·높이 채우기, 표 내부 스크롤, 같은 헤더 검증.
6. `원래대로` 및 `ESC`로 복귀; 표/그래프 다른 데이터 오염 금지.
7. 브라우저 확대 100%, 125%에서 2~6 반복.

## 그래프 최대화

- [ ] 1번 면적 비교: 막대와 수치/축/단위/정확한 값 표까지 최대 화면 적응.
- [ ] 2번 층 구성: 10개 라인, 1F~3F 층/면적 숫자 잘림 없이 표시.
- [ ] 3번 히트맵: 전체 셀/가용률/단위가 최대 화면에 맞춰 재배치.
- [ ] 세 그래프 각각 `최대화↔원래대로`, ESC 복귀.

## 데이터/버전/보안

- [ ] Excel 46열 다운로드 정상, 열 헤더/순서와 FIELDS 동일.
- [ ] 수정본 검증이 변경/중복/누락/삭제 의심을 구분.
- [ ] 변경 전후 차이·버전 메타데이터를 조회할 수 있음(로컬 구현).
- [ ] `data/equipment.json`과 `data/line-info-state.json`이 **예상치 않게 삭제/덮어쓰기되지 않음**.
- [ ] UI 비밀번호가 보안 장치가 아니라는 경고가 있음.
- [ ] 사내 SSO/권한/원격 저장은 테스트하지 않았다면 **미검증** 표시.
