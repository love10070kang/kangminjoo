# 10. 향후 EDS 전문가 육성 위키 / 업무 교육 플랫폼 연계 (기획 기록)

> **중요:** 여기 적힌 항목은 별도로 논의한 중장기 플랫폼 요구사항입니다. 현재 v4.3의 16개 업무 메뉴를 없애거나 교육 메뉴로 대체하라는 의미가 아닙니다. 운영 정보/전문가 육성을 일관된 데이터 원칙으로 연결할 때 참고합니다.

## 1. 신입→전문가 육성의 4대 목적

1. 신입부터 마스터 전문가를 단계적으로 육성.
2. 담당자별로 다른 업무 수행법을 프로세스와 데이터로 표준화.
3. 교육 이수, 실무 수행, 검토 산출물, 인증·역량을 하나로 연결.
4. AI·자동화·벤치마킹 등 미래 실무 역량 확보.

## 2. 사용자 범위와 업무 영역

신입 / 실무 / 선임·전문 / 마스터·전문가 / 관리자 / 유관부서의 6그룹. 업무는 신규라인·증설·설비투입·이전/재배치·반출·제원변경·공간최적화·중장기전략·긴급이슈의 9유형.

`요청 → 입력자료 확보 → 적합성 검증 → Layout 검토 → 협의·승인 → 현장 확인 → 최종 도면 및 개정 이력`

업무 결과의 최상위 산출물은 **최종 Layout 도면**과 **도면 변경·개정이력**이며, 승인본 판단은 '파일 날짜가 최근인지'와 다릅니다. 실제 CAD/BIM/As-built 원본은 회사 파일서버에 보존하고 위키에서 연결하는 것이 원칙입니다.

## 3. 신규 설비 투입 SOP 기획 요점

- 착수: 요청 목적/대상/일정/담당 범위와 승인 주체 확인.
- 입력: 설비 종류·모델·제원, 생산 요구, FAB·층·구역, 공간·바닥·층고, 반입 동선, Utility, 도면/최신 승인 정보 등을 확보하고 **출처·확보 상태** 기록.
- 검증: 자료 신뢰성, 개정·버전, 필수 값, 기준 단위 확인.
- 적합성: 공간·정비/작업간격·하중·진동·층고·Access Floor·반입·Utility·안전/환경·운영영향 등을 종합 검토.
- 대응: 미충족 사항별 대안, 조건 변경, 타 구역, 일정/예산 협의, 보완 도면, 예외 승인.
- 승인: 실무 디자이너가 근거와 대안이 담긴 안 제시 → 관리자 및 유관부서 검토·승인.
- 종료: 현장 적합성 재확인 후 승인 도면과 변경이력을 정리.

※ 위 순서는 교육 문서 수준 요약입니다. SOP별 세부 항목 수·평가 문항은 승인된 상세 체크리스트를 후속 문서에서 관리합니다.

## 4. 교육·역량 L1~L7 방향

- L1~L2: 기본 용어, 라인/FAB 구조, 설비/공간/도면/제원/반입/안전 등 기초 교육과 멘토링.
- L3: 교육과 실무 경험을 종합해 자기 점검+선임 검토. 최종 산출물의 품질 체크리스트 `PASS / N/A` 사용. 단순 수행 건수만으로 인증하지 않음.
- L4~L7: 전문분야 경험, 예외 판단, 개선 주도, 표준화/조직 기여 등 수준별 검증. 구체적인 증빙·심사는 단계별 원안 문서로 확정.
- 개인별 현재/목표 레벨, 교육이수, 실습, 실제 프로젝트 경험, 증빙자료, 평가자/멘토, 인증/승인 상태를 기록할 수 있는 방향.

## 5. 장기 대시보드/현황표

- 상단 카드 개념: `현재 레벨 / 학습·실습 / 진행 업무 / 검토·승인 대기`.
- 하단 연동 표 후보: `업무 현황 / 교육·실습 현황 / 역량 현황 / 검토·승인 현황 / 도면·자료 현황`.
- 교육 이수와 실무 수행 증빙은 연결하되, 실제 인증 여부는 선임/관리자 승인으로 구분.
- 검색/필터/정렬: 직원번호·이름, 소속·직무, 역량명, L레벨, 실무경험, 증빙자료, 교육, 평가/승인 상태. 수정일 최신순 정렬이 기본값으로 논의됨.

## 6. 개발 지침

- **현재 16개 업무용 메뉴 구조는 그대로 유지**하고 별도 교육/역량 정보구조는 관리자 승인 후 추가.
- 새 업무/역량 입력 항목은 기존 46개 `라인 기본정보 RAW`와 섞지 않음.
- AI 상담/자동 판정은 근거 데이터·보안 정책·승인자가 갖춰진 후 구현. 추측 기반 승인/설치 가능 판정 금지.
- 사용자에게 이미 승인된 기능/레이아웃을 삭제하지 않고 독립된 페이지로 단계적 확장.
